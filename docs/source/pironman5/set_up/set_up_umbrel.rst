Setting Up on Umbrel OS
======================================================================

If you have installed Umbrel OS on your Raspberry Pi 5, you can configure the Pironman 5 MAX through the command line. Follow the steps below to complete the setup:

#. Connect your Raspberry Pi 5 to your network using an Ethernet cable. This is required to ensure your Raspberry Pi has internet access.

#. Open your browser and visit: ``http://umbrel.local``. If the page does not open, check your router for the Umbrel device's IP address, for example: ``http://192.168.1.50``

   .. image:: img/umbrel_local.png

#. Create your Umbrel account by setting a username and password. This password will be required for future remote access, so please keep it safe.

   .. image:: img/umbrel_account.png

#. Click **Next** to complete the Umbrel setup and enter the desktop environment.

   .. image:: img/umbrel_desktop.png

#. Click the **App Store** icon to open it.

   .. image:: img/umbrel_app_store.png

#. In the Umbrel App Store, click the **Community App Store** button in the top-right corner.

   .. image:: img/umbrel_community_app.png

#. Enter our custom repository URL: ``https://github.com/sunfounder/umbrel-community-app-store/``

   .. image:: img/umbrel_url.png

#. After adding the repository, click **Open** to access the **SunFounder Store**.

   .. image:: img/umbrel_open.png

#. In the **SunFounder App Store**, you will see two available apps. Select either **Pironman 5** or **Pironman 5 Max**.

   .. image:: img/umbrel_sf_app.png

#. Click **Install** to begin the installation.

   .. image:: img/umbrel_app_install.png

#. Once the installation is complete, click **Open** to launch the Dashboard.

   .. image:: img/umbrel_dashboard.png
