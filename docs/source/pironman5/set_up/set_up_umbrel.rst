Configuration sur Umbrel OS
======================================================================

Si vous avez installé Umbrel OS sur votre Raspberry Pi 5, vous pouvez configurer le Pironman 5 MAX en ligne de commande. Suivez les étapes ci-dessous pour terminer la configuration :

#. Connectez votre Raspberry Pi 5 à votre réseau à l'aide d'un câble Ethernet. Cela est nécessaire pour garantir que votre Raspberry Pi ait accès à Internet.

#. Ouvrez votre navigateur et rendez-vous sur : ``http://umbrel.local``. Si la page ne s'ouvre pas, vérifiez l'adresse IP de l'appareil Umbrel sur votre routeur, par exemple : ``http://192.168.1.50``

   .. image:: img/umbrel_local.png

#. Créez votre compte Umbrel en définissant un nom d'utilisateur et un mot de passe. Ce mot de passe sera requis pour les futurs accès à distance, conservez-le en lieu sûr.

   .. image:: img/umbrel_account.png

#. Cliquez sur **Suivant** pour terminer la configuration d'Umbrel et accéder à l'environnement de bureau.

   .. image:: img/umbrel_desktop.png

#. Cliquez sur l'icône **App Store** pour l'ouvrir.

   .. image:: img/umbrel_app_store.png

#. Dans l'Umbrel App Store, cliquez sur le bouton **Community App Store** dans le coin supérieur droit.

   .. image:: img/umbrel_community_app.png

#. Saisissez l'URL de notre dépôt personnalisé : ``https://github.com/sunfounder/umbrel-community-app-store/``

   .. image:: img/umbrel_url.png

#. Après avoir ajouté le dépôt, cliquez sur **Ouvrir** pour accéder à la **SunFounder Store**.

   .. image:: img/umbrel_open.png

#. Dans la **SunFounder App Store**, vous verrez deux applications disponibles. Sélectionnez **Pironman 5** ou **Pironman 5 Max**.

   .. image:: img/umbrel_sf_app.png

#. Cliquez sur **Installer** pour commencer l'installation.

   .. image:: img/umbrel_app_install.png

#. Une fois l'installation terminée, cliquez sur **Ouvrir** pour lancer le tableau de bord.

   .. image:: img/umbrel_dashboard.png
