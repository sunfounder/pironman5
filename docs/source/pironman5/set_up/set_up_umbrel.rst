Konfiguration unter Umbrel OS
======================================================================

Wenn du Umbrel OS auf deinem Raspberry Pi 5 installiert hast, kannst du den Pironman 5 MAX über die Befehlszeile konfigurieren. Folge den untenstehenden Schritten, um die Einrichtung abzuschließen:

#. Verbinde deinen Raspberry Pi 5 über ein Ethernet-Kabel mit deinem Netzwerk. Dies ist erforderlich, um sicherzustellen, dass dein Raspberry Pi Internetzugang hat.

#. Öffne deinen Browser und besuche: ``http://umbrel.local``. Wenn die Seite nicht geöffnet wird, überprüfe in deinem Router die IP-Adresse des Umbrel-Geräts, z.B.: ``http://192.168.1.50``

   .. image:: img/umbrel_local.png

#. Erstelle dein Umbrel-Konto, indem du einen Benutzernamen und ein Passwort festlegst. Dieses Passwort wird für zukünftige Fernzugriffe benötigt, also bewahre es sicher auf.

   .. image:: img/umbrel_account.png

#. Klicke auf **Next**, um die Umbrel-Einrichtung abzuschließen und die Desktop-Umgebung zu betreten.

   .. image:: img/umbrel_desktop.png

#. Klicke auf das **App Store**-Symbol, um es zu öffnen.

   .. image:: img/umbrel_app_store.png

#. Klicke im Umbrel App Store auf die Schaltfläche **Community App Store** in der oberen rechten Ecke.

   .. image:: img/umbrel_community_app.png

#. Gib die URL unseres benutzerdefinierten Repositorys ein: ``https://github.com/sunfounder/umbrel-community-app-store/``

   .. image:: img/umbrel_url.png

#. Nachdem du das Repository hinzugefügt hast, klicke auf **Open**, um auf den **SunFounder Store** zuzugreifen.

   .. image:: img/umbrel_open.png

#. Im **SunFounder App Store** siehst du zwei verfügbare Apps. Wähle entweder **Pironman 5** oder **Pironman 5 Max** aus.

   .. image:: img/umbrel_sf_app.png

#. Klicke auf **Install**, um die Installation zu starten.

   .. image:: img/umbrel_app_install.png

#. Sobald die Installation abgeschlossen ist, klicke auf **Open**, um das Dashboard zu starten.

   .. image:: img/umbrel_dashboard.png
