Configurazione su Umbrel OS
======================================================================

Se hai installato Umbrel OS sul tuo Raspberry Pi 5, puoi configurare il Pironman 5 MAX dalla riga di comando. Segui i passaggi qui sotto per completare la configurazione:

#. Collega il tuo Raspberry Pi 5 alla rete usando un cavo Ethernet. Questo è necessario per garantire che il Raspberry Pi abbia accesso a Internet.

#. Apri il browser e visita: ``http://umbrel.local``. Se la pagina non si apre, controlla sul router l'indirizzo IP del dispositivo Umbrel, ad esempio: ``http://192.168.1.50``

   .. image:: img/umbrel_local.png

#. Crea il tuo account Umbrel impostando un nome utente e una password. Questa password sarà richiesta per futuri accessi remoti, quindi conservala al sicuro.

   .. image:: img/umbrel_account.png

#. Clicca su **Avanti** per completare la configurazione di Umbrel e accedere all'ambiente desktop.

   .. image:: img/umbrel_desktop.png

#. Clicca sull'icona **App Store** per aprirla.

   .. image:: img/umbrel_app_store.png

#. Nell'Umbrel App Store, clicca sul pulsante **Community App Store** nell'angolo in alto a destra.

   .. image:: img/umbrel_community_app.png

#. Inserisci l'URL del nostro repository personalizzato: ``https://github.com/sunfounder/umbrel-community-app-store/``

   .. image:: img/umbrel_url.png

#. Dopo aver aggiunto il repository, clicca su **Apri** per accedere al **SunFounder Store**.

   .. image:: img/umbrel_open.png

#. Nel **SunFounder App Store**, vedrai due app disponibili. Seleziona **Pironman 5** o **Pironman 5 Max**.

   .. image:: img/umbrel_sf_app.png

#. Clicca su **Installa** per avviare l'installazione.

   .. image:: img/umbrel_app_install.png

#. Una volta completata l'installazione, clicca su **Apri** per avviare la Dashboard.

   .. image:: img/umbrel_dashboard.png
