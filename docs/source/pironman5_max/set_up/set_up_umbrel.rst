Configuración en Umbrel OS
======================================================================

Si has instalado Umbrel OS en tu Raspberry Pi 5, puedes configurar el Pironman 5 MAX a través de la línea de comandos. Sigue los pasos a continuación para completar la configuración:

#. Conecta tu Raspberry Pi 5 a la red mediante un cable Ethernet. Este paso es esencial para garantizar que la Raspberry Pi tenga acceso a Internet.

#. En tu navegador, visita: ``http://umbrel.local``. Si la página no se abre, revisa en el enrutador la dirección IP del dispositivo Umbrel, por ejemplo: ``http://192.168.1.50``

   .. image:: img/umbrel_local.png

#. Crea tu cuenta de Umbrel configurando un nombre de usuario y una contraseña. Esta contraseña se utilizará para futuros accesos remotos a Umbrel, así que asegúrate de recordarla.

   .. image:: img/umbrel_account.png

#. Haz clic en **Next** para completar la configuración de Umbrel y entrar al entorno de escritorio.

   .. image:: img/umbrel_desktop.png

#. Haz clic en el ícono de **App Store** para abrirlo.

   .. image:: img/umbrel_app_store.png

#. En la Umbrel App Store, haz clic en el botón **Community App Store** en la esquina superior derecha.

   .. image:: img/umbrel_community_app.png

#. Ingresa la URL de nuestro repositorio personalizado: ``https://github.com/sunfounder/umbrel-community-app-store/``

   .. image:: img/umbrel_url.png

#. Después de agregar el repositorio, haz clic en **Open** para acceder a la **SunFounder Store**.

   .. image:: img/umbrel_open.png

#. En la **SunFounder App Store**, verás dos aplicaciones disponibles. Selecciona **Pironman 5** o **Pironman 5 Max**.

   .. image:: img/umbrel_sf_app.png

#. Haz clic en **Install** para comenzar la instalación.

   .. image:: img/umbrel_app_install.png

#. Una vez completada la instalación, haz clic en **Open** para abrir el Panel de Control.

   .. image:: img/umbrel_dashboard.png
