Caratteristiche
======================

**Parametri**

* Dimensioni: 111,9 x 78,5 x 117 mm
* Materiali
    * Corpo principale: lega di alluminio
    * Pannelli laterali: acrilico
* Piattaforma supportata: Raspberry Pi 5
* Alimentazione: USB Type C, 5V/5A
* Interfacce
    * GPIO standard Raspberry Pi a 40 pin
    * Slot Micro SD a molla
    * Ingresso alimentazione USB Type C
    * 2 x USB 2.0
    * 2 x USB 3.0
    * Porta LAN Gigabit
    * 2 x HDMI Type A 4Kp60
* Pulsante di accensione in metallo
* Schermo OLED: 0,96'' risoluzione 128x64
* 1 ventola CPU, 2 ventole GPIO: 40x40x10 mm
* 4 x LED RGB WS2812-5050
* Ricevitore IR 38 KHz
* Dissipatore a torre
* 2 x PCIe 2.0 x1 M.2 M key 2230, 2242, 2260, 2280 per SSD NVMe o acceleratore AI
* Batteria 1220 per RTC
