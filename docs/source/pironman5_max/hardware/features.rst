Caractéristiques
======================

**Spécifications**

* Dimensions : 111,9 x 78,5 x 117 mm
* Matériau
    * Corps principal : alliage d'aluminium
    * Deux panneaux latéraux : acrylique
* Plateforme supportée : Raspberry Pi 5
* Alimentation électrique : USB Type-C, 5V/5A
* Interfaces
    * GPIO 40 broches standard du Raspberry Pi
    * Emplacement MicroSD à ressort
    * Entrée d'alimentation USB Type-C
    * 2 x USB 2.0
    * 2 x USB 3.0
    * Port Ethernet Gigabit
    * 2 x HDMI Type A 4Kp60
* Bouton d'alimentation métallique
* Écran OLED : 0,96 pouce, résolution 128x64
* 1 x ventilateur CPU, 2 x ventilateurs GPIO : 40 x 40 x 10 mm
* 4 x LEDs RGB WS2812-5050
* Récepteur IR 38 kHz
* Refroidisseur tour
* 2 x PCIe 2.0 x1 M.2 M key (2230, 2242, 2260, 2280) pour SSD NVMe ou accélérateur IA
* Pile 1220 pour RTC
