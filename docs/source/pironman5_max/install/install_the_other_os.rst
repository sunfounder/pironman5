Instalar Ubuntu / Kali Linux / Homebridge / Home Assistant
=========================================================================

Puedes elegir el método de instalación según si dispones de una tarjeta Micro SD o de un SSD NVMe.

**Usar solo una tarjeta Micro SD**

  Si estás utilizando una tarjeta Micro SD, puedes seguir directamente el primer método que se describe a continuación.

**Usar un SSD M.2 NVMe**

  * Si utilizas un SSD M.2 NVMe, también necesitarás un **adaptador/carcasa para SSD M.2 NVMe** para conectar el SSD a tu ordenador y seguir el segundo método para instalar el sistema operativo.
